# GNS3 Labs

Hands-on networking labs built in GNS3 for practicing and documenting networking concepts, configuration, verification, and troubleshooting.

## Labs

### CCNA Network Lab

A continuously evolving network built incrementally from basic switching through more advanced CCNA-level topics.

The lab includes configuration files, topology information, verification results, troubleshooting exercises, and notes gathered as the network develops.

## Environment

- Ubuntu Desktop
- GNS3
- Cisco IOSvL2
- Cisco IOSv
- VPCS
- Wireshark

## Repository Notes

Cisco IOS images, virtual disk images, runtime files, credentials, secrets, and other proprietary or unnecessary files are not included in this repository.
